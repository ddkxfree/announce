# 企业智能体开发计划

这个仓库放一份按周执行的学习计划，面向已经会写 Python、想做企业智能体的后端或全栈开发者。

计划文件：[docs/12-week-agent-plan.md](docs/12-week-agent-plan.md)

12 周做三个能讲清楚的作品：

1. **会议纪要抽取器**（第 1–3 周）：结构化输出和最小评测
2. **制度问答**（第 4–6 周）：带来源、带权限的 RAG
3. **采购申请助手**（第 7–12 周）：工具网关、LangGraph、人工确认、HTTP 服务和回归集

企业里目前最常见的落地，是「知识检索 + 只读工具 + 可暂停的工作流」，高风险动作等人确认后再执行。计划按这个顺序排，每周都有目录和验收标准。
